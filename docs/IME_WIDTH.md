# 전각 영문 대응

beta.10 후보에 추가한 Windows용 선택 기능입니다. 기존 한글 조합·한자 변환 경로를 대체하지 않습니다. 기본값은 꺼짐입니다.

## 사용법

한국어 Microsoft IME의 영문 상태로 채팅 등 입력창을 연 뒤 사용합니다.

- `F7`: 입력창을 닫지 않고 전각 상태 복구를 한 번 요청합니다. 성공 여부를 게임 상태 메시지로 알려 줍니다.
- `Shift+F7`: 반각 영문 유지를 켜거나 끕니다. 켜면 입력창 진입 시 복구를 시도하고, 새로 확정된 전각 영문·숫자도 범위를 확인한 뒤 보정합니다.
- `config/hangul.properties`의 `halfWidthLatin=true`: 반각 영문 유지 설정입니다. 파일이 없거나 값이 올바르지 않으면 꺼진 상태로 시작합니다. 설정 변경 시에만 파일을 만듭니다.

F7은 텍스트 입력이 활성화된 게임 창에서만 처리합니다. Ctrl·Alt·Super와 함께 누른 F7, 게임 조작 중의 F7, Windows 외 운영체제의 F7은 가로채지 않습니다. F6 비상 한글 모드와는 별개입니다.

## 변경하는 범위

Windows가 보고한 한국어 IME의 **영문 모드**에서 전각 플래그만 해제합니다. 한영 모드, 입력기 열림 상태, 문장 변환 설정과 다른 변환 플래그는 보존하며 변경 후 다시 확인합니다. 조합 중이거나 후보 목록이 있는 경우에는 복구하지 않습니다. 입력기를 껐다 켜거나 한영키·Esc를 대신 누르지 않습니다.

반각 유지 옵션을 켠 경우 문자 확정 이벤트에서 다음 범위만 보정할 수 있습니다.

| 새로 입력된 문자 | 보정 |
| --- | --- |
| `Ａ`–`Ｚ` | `A`–`Z` |
| `ａ`–`ｚ` | `a`–`z` |
| `０`–`９` | `0`–`9` |

붙여넣기, 기존 입력값, 책·표지판의 저장 내용, 전각 공백·문장부호와 다른 Unicode 문자는 변환하지 않습니다. 전체 문자열에 NFKC 정규화를 적용하지 않습니다. 의도적으로 전각 영문을 입력하려면 유지 옵션을 끄세요.

Minecraft의 텍스트 입력 활성 상태를 사용하므로 단일행 입력창뿐 아니라 책·표지판·외부 위젯도 같은 문자 확정 경로를 사용할 수 있습니다. 외부 위젯의 직접 문자열 삽입이나 붙여넣기는 대상이 아닙니다.

## 안전성과 의존성

- Minecraft의 실제 GLFW 또는 SDL 창에서 HWND를 가져옵니다. 다른 모드가 라이브러리를 포함했다는 이유로 백엔드를 선택하지 않습니다.
- 그 창이 현재 전경에 있고 현재 프로세스·스레드 소유인지 확인합니다. Alt+Tab으로 다른 앱이 활성화된 상태에서는 변경하지 않습니다.
- 상태나 조합 여부를 확인할 수 없으면 원래 입력으로 돌아갑니다. 반각 변경 요청이 거절돼도 입력 상태가 보존돼 있다면 선택한 문자 보정만 적용할 수 있습니다.
- Minecraft가 이미 제공하는 JNA와 Windows 시스템 API를 사용합니다. 추가 필수 모드나 라이브러리, DLL은 내려받거나 포함하지 않습니다.
- 매 프레임·틱마다 상태를 조회하지 않습니다. 입력창 활성화, 복구키, 대상 전각 문자 확정 때만 처리합니다. 설정이 꺼져 있거나 일반 문자를 입력할 때는 네이티브 조회를 하지 않습니다.
- 입력 내용이나 후보 문자열을 읽어 저장하거나 로그로 남기지 않습니다. 조합·후보 여부를 확인할 때는 길이만 조회합니다.

Windows의 현대식 입력기가 IMM 상태 조회·변경을 지원하지 않는 경우에는 작동하지 않을 수 있습니다. 언어와 조합 상태를 확인하지 못한 채 문자를 강제로 바꾸지 않습니다. API 호출 성공과 간헐적 현상의 원인 해결도 구분합니다.

## 실제 확인이 필요한 항목

자동 검사는 Unicode 보정 범위, 설정 보존, 상태 변경 실패·재확인 불일치, 다른 언어·한글 모드·조합 중 보호, 실제 로더의 문자 훅과 Windows 함수 연결을 다룹니다. 게임 창이나 IME 모드를 변경하지 않으며 실제 후보창·포커스 복구 검증은 대신하지 않습니다.

공개 전에는 같은 후보 JAR로 다음을 확인해야 합니다.

1. 전각 영문 현상이 발생한 상태에서 채팅을 닫지 않고 F7로 복구되는지 확인합니다.
2. Shift+F7로 유지 옵션을 켠 뒤 한영 전환·채팅 재진입·Alt+Tab을 반복하며 전각 영문·숫자 입력을 확인합니다.
3. 한글 조합과 한자 후보 선택·취소 중 F7이 내용을 확정하거나 지우지 않는지 확인합니다.
4. 책·표지판·REI 입력창에서 커서·선택·저장·붙여넣기를 확인합니다. 전각 문장부호와 다른 언어의 의도적인 전각 입력도 보존되는지 확인합니다.
5. 게임을 다시 실행했을 때 유지 설정이 이어지고, 설정을 끄면 기존 입력으로 돌아오는지 확인합니다.

간헐적 원인을 재현하지 못한 상태에서는 이 기능을 근본 원인 수정이나 완전한 자동 복구로 안내하지 않습니다.

## API 근거

Windows의 [IME 변환 모드](https://learn.microsoft.com/en-us/windows/win32/intl/ime-conversion-mode-values), [상태 조회](https://learn.microsoft.com/en-us/windows/win32/api/immdev/nf-immdev-immgetconversionstatus), [상태 변경과 제한 사항](https://learn.microsoft.com/en-us/windows/win32/api/immdev/nf-immdev-immsetconversionstatus)을 기준으로 합니다. SDL 창의 HWND는 [공식 창 속성 API](https://wiki.libsdl.org/SDL3/SDL_GetWindowProperties)로 얻습니다.
