# Architecture

Hangul은 운영체제 IME를 대체하지 않고 Minecraft의 입력·렌더링 경계만 보완하는 클라이언트 모드입니다.

## 설계 원칙

- **Native first:** 한/영 전환, 조합 규칙, 한자 후보는 운영체제 IME에 맡깁니다.
- **임시 조합 상태:** 조합 중인 문자열은 화면에만 합성하며 실제 위젯 값이나 네트워크 패킷에는 넣지 않습니다.
- **이벤트 기반 처리:** 입력 이벤트와 검색 트리 재생성 시점에만 동작하고 상시 전체 목록 순회를 두지 않습니다.
- **작은 의존성 표면:** Fabric Loader 외 런타임 라이브러리, 네이티브 DLL, 설정 프레임워크를 요구하지 않습니다.
- **실패 격리:** 명령어 검색 보조가 실패해도 바닐라 추천 결과를 그대로 반환합니다.

## 주요 경로

| 영역 | 처리 방식 |
| --- | --- |
| 단일행 입력 | `EditBox`의 preedit을 실제 커서 위치에 임시 합성 |
| 다중행 입력 | `MultiLineEditBox`의 줄바꿈 결과에 조합 문자열을 반영한 뒤 렌더 후 복원 |
| 표지판 | 줄별 선택·커서 좌표를 보존하면서 조합 문자열 렌더 |
| 한자 후보 | 현재 렌더 커서의 화면 좌표를 운영체제 입력 관리자에 전달 |
| 아이템·조합법 검색 | 언어 검색 트리 생성 시 원문과 초성 문자열을 함께 색인 |
| 자판 검색 | 짧은 질의만 두벌식으로 변환해 기존 접미 배열을 재사용 |
| 명령어 추천 | 현재 서버가 공개하고 사용을 허용한 리터럴만 자판·음차 규칙으로 보완 |

## 성능 모델

일반 입력에서는 preedit이 없으면 추가 문자열 합성을 수행하지 않습니다. 초성은 검색할 때마다 아이템을 순회하지 않고 검색 트리가 만들어질 때 한 번 추가됩니다. 질의 시에는 기존 `SearchTree`를 최대 두 번 조회하며, 두 결과가 모두 있을 때만 순서 보존 중복 제거 컬렉션을 만듭니다. 다중 단어 교집합은 전체 문구 검색 결과가 비었을 때만 실행됩니다.

명령어의 한글 보정은 입력에 한글이 있을 때만 비동기 후처리를 연결합니다. F6 비상 조합기는 키 분류와 겹받침 분리에 임시 객체를 만들지 않습니다.

## 호환성 경계

현재 대상은 Minecraft 26.2, Fabric Loader 0.19.3 이상, Java 25입니다. 바닐라 `EditBox`, `MultiLineEditBox`, `TextFieldHelper` 경로를 사용하지 않는 외부 모드의 자체 위젯은 별도 어댑터가 필요할 수 있습니다.
