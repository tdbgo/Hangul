# 1.3.0-beta.6 배포 준비 상태

현재는 미공개 검증 후보입니다. 로더별 자동 검사가 통과하더라도 Windows IME 실사용 검사를 대신하지 않습니다. 공개 전에는 [릴리스 체크리스트](RELEASE_CHECKLIST.md)의 남은 항목을 확인해야 합니다.

2026-09-06: 확장된 표지판·입력창 회귀 검사를 포함해 40개 로더·게임 조합과 최소 Fabric Loader 0.19.3의 3개 조합이 모두 통과했습니다. 최종 패키지·소스 압축파일 검사도 통과했습니다. 기존 후보와 비교하면 NeoForge 아이콘 메타데이터만 변경되었으며, 세 플랫폼의 입력 클래스는 변경되지 않았습니다.

## 검증 범위

| 구분 | 확인 범위 | 한계 |
| --- | --- | --- |
| 자동 검사 | 동일 JAR의 메타데이터·바이트코드·Mixin 적용, 검색, 입력창 조합 이벤트와 원문 복원 | OS 키 전달·후보창·화면 픽셀을 검사하지 않음 |
| 표지판 회귀 검사 | 변환된 게임 클래스의 Up/Down/Enter 줄 이동·순환, 선택 교체, 한자 문자 확정, 취소·렌더 예외 복원 | 네이티브 창 없는 테스트용 상태에서 실행. 월드 저장·IME 후보 선택을 대신하지 않음 |
| Forge 26.2 실제 실행 | 한글 채팅·책·표지판 입력과 저장, 전체화면 전환, 리소스 재로딩, 블록 드롭, 저장·종료 | 다른 Forge 버전과 확장 IME 사례는 별도 확인 필요 |
| NeoForge 26.2 실제 실행 | 조합·Backspace, 채팅, 표지판 저장, 책 선택 교체·두 페이지 저장·재열기, 전체화면, 리소스 재로딩, 한자 변환 확인 | 아이콘 메타데이터 변경 전 파일에서 확인. OS 표지판 방향키 전달은 미확정 |
| Quilt 26.2 실제 실행 | 패키지 로딩·메뉴·별도 월드 진입 | 실제 한글 조합 미확인 |
| 26.3 시험판 | 선언된 버전의 자동 검사 | 실제 Windows IME·SDL3 창 동작 미확인 |

## 공개 전 남은 항목

- Quilt에서 실제 한글 조합·확정·취소와 저장을 확인합니다.
- 최신 대상 시험판에서 Windows IME를 확인합니다.
- IME 사용 중 표지판 방향키 전달, 한자 후보 취소·위치, GUI 배율·창 크기·포커스 전환과 전각 입력 관련 체크리스트를 마칩니다.
- 최종 파일의 해시와 검증 기록을 대조합니다. 파일이 바뀌면 변경 범위에 맞춰 재검사합니다.
- 원격 CI 결과와 공개 이력 검사를 확인한 후 업로드합니다. 로컬 성공을 원격 CI 성공으로 표기하지 않습니다.

실험적 지원 범위나 베타 표시만으로 위 항목이 자동 통과되는 것은 아닙니다. 미확인 항목이 남아 있으면 전체 로더의 배포 준비가 완료되었다고 표시하지 않습니다.
