# 배포 준비 상태

## 1.3.0-beta.8 — 26.4 Snapshot 1 대응

2026-09-23: Minecraft 26.4의 첫 스냅샷을 Fabric·Quilt 시험 지원 대상으로 추가했습니다. 26.4 정식판이나 후속 스냅샷은 아직 지원 대상으로 선언하지 않습니다. NeoForge와 Forge의 26.4 로더는 확인 시점에 배포되지 않아 각각 기존 26.3·26.2 범위를 유지합니다. 실행 코드는 beta.7과 같고, 이번 변경은 버전 선언·검증 행렬·문서에 한정됩니다.

- Windows 전체 검사에서 동일 배포 후보의 Fabric·Quilt 각 18개, NeoForge 5개, Forge 4개, 총 45개 로더·게임 조합이 통과했습니다. 최소 Fabric Loader 0.19.3의 대표 대상 5개도 통과했습니다.
- 26.4 Snapshot 1에서 Fabric Loader 0.19.5·0.19.3 및 Quilt Loader 0.31.0-beta.4의 실제 로더가 13개 대상 클래스와 42개 훅을 적용했습니다. 조합 이벤트, 키 통과, 검색, 책·표지판 위젯 자동 검사도 성공했습니다.
- Fabric 개발 클라이언트가 26.4 기본 Vulkan 렌더러로 실행되어 격리된 새 월드에 진입했습니다. 완성된 한글 문자열을 채팅에 표시·전송했고, 월드를 저장한 뒤 정상 종료했습니다.
- 이 화면 검사는 자동 도구로 완성된 유니코드 문자열을 넣었습니다. 이후 사용자가 별도 26.4 테스트에서 한글 조합과 한자 입력이 정상 동작한다고 확인했습니다. 확인은 테스터 보고이며, 자동 검사나 화면 기록으로 관찰한 결과와 구분합니다. 책·표지판의 26.4 실사용 세부 항목은 별도 기록이 없으므로 자동 위젯 검사 범위까지만 기술합니다.
- 각 배포 후보의 크기와 SHA-256: Fabric 56,399 bytes / `5eee69bc381d46df8882469e9f88e120bc45e11e616f329fa0dd92fc345528a1`; NeoForge 55,734 bytes / `4c98d606510daeff9fff71d10ed5b1fc158be5be3ba0fb6252839b9f3fa36ff5`; Forge 55,307 bytes / `c9ee8f602b625cfe4905087d905090313d3acfa9ca7994e87d65a20b7947525e`.

원격 CI 결과와 최종 업로드 파일의 해시는 공개 릴리스에서도 확인합니다.

## 1.3.0-beta.7 — 26.3 정식판 대응

2026-09-17: beta.7 배포 준비 검사를 마치고 공개했습니다. Fabric·Quilt·NeoForge에 Minecraft 26.3 정식판을 추가했습니다. Forge는 공식 26.3 로더가 없어 26.2까지의 기존 범위를 유지합니다. 모든 배포 JAR은 계속 26.2를 기준으로 빌드합니다.

- Fabric 0.19.5·Quilt 0.31.0-beta.4의 26.3 검사: 동일 Fabric 후보 JAR의 바이너리 검사와 13개 대상 클래스·42개 훅, 위젯·검색·표지판 검사 통과.
- NeoForge 26.3.0.3-beta의 26.3 검사: 동일 NeoForge 후보 JAR의 13개 대상 클래스·42개 훅, 위젯·검색·표지판 및 입력 백엔드 검사 통과.
- 최종 Windows 전체 검사: Fabric·Quilt 각 17개, NeoForge 5개, Forge 4개로 총 43개 로더·게임 조합 통과. 최소 Fabric Loader 0.19.3의 26.1·26.2·26.3-pre-2·26.3 추가 4개 조합도 통과했습니다.
- 각 자동 실행에서 13개 클래스·42개 훅, 키 이벤트·단축키 처리, 위젯·검색·표지판 검사를 수행했습니다. 이 검사는 OS의 실제 키 전달과 구분합니다. 한글 11,172음절 회귀 검사와 세 파일의 패키지 검사도 통과했습니다.
- 완료 기록 누락·이전 실행 기록 잔존·후보 해시 불일치가 실제 실패로 처리되는지 별도 검사했습니다. 정상 기록만 통과했습니다.
- 세 플랫폼 모두 배포 클래스 바이트가 beta.6와 동일합니다. 지원 선언과 검증·빌드 절차 변경이며 새 실행 의존성은 없습니다.
- [원격 CI](https://github.com/tdbgo/Hangul/actions/runs/35177486520)는 `72f1a7f`에서 29개 작업이 모두 성공했습니다. 전체 선언 버전·로더 검사와 최종 패키지 검사도 포함합니다.
- 문서를 반영한 `779c9f5`의 [후속 CI](https://github.com/tdbgo/Hangul/actions/runs/35179206066)도 29개 작업이 모두 성공했습니다.
- CI의 세 JAR과 로컬 후보의 실행 클래스가 모두 같습니다(Fabric 29개, NeoForge 30개, Forge 29개). 리소스·메타데이터의 의미도 같으며, 파일 해시 차이는 줄바꿈과 Fabric 매니페스트의 목록 순서에서 발생합니다. 배포에는 아래 로컬 후보를 유지합니다.
- 실제 26.3 검사 진행 상황은 아래에 구분합니다. beta.6의 테스터 완료 보고를 이번 버전의 결과로 재사용하지 않습니다.
- 2026-09-17 13:53 KST에 공식 로더 메타데이터를 다시 확인했습니다. Fabric 최신은 0.19.5, NeoForge 26.3 최신은 26.3.0.3-beta이며 Forge 26.3 배포는 없습니다. 공개 직전 다시 확인합니다.

### 26.3 실제 입력 검사

| 대상 | 직접 관찰한 항목 | 테스터 확인과 범위 |
| --- | --- | --- |
| Fabric 0.19.5 | F6 없는 네이티브 `ㄱ → 가 → 각`, Backspace로 받침 삭제, 표지판 여러 줄 저장·재열기, 전체화면 왕복, 책 선택 교체·두 줄 입력·두 페이지 저장·재열기, 월드 정상 저장·종료 | 이 실행에서 한자 후보 선택·취소 정상 동작 확인 |
| Quilt 0.31.0-beta.4 | 네이티브 채팅 즉시 조합·단일 전송, 한국어 언어 적용에 따른 리소스 재로드, 재로드 후 책 두 줄 조합·저장·재열기, 전체화면 왕복, 표지판 선택 교체·Enter 줄 이동·저장 후 월드 표시, 월드 정상 저장·종료 | 이 실행에서 한글·한자 입력 정상 동작 확인 |
| NeoForge 26.3.0.3-beta | 고정된 후보 JAR 로딩·별도 월드 진입, 책 선택 교체 후 네이티브 `가` 조합·전체화면 표시, 다음 페이지 이동, 책 편집 종료와 월드 정상 저장·종료 | 이 실행에서 한글·한자 후보 선택·취소, 책·표지판 저장·재열기, 표지판 위/아래 방향키, 창 전환 후 입력, 한자 후보창 위치를 모두 확인했다고 보고 |

테스터에게 저장·재열기, 방향키, 창 전환, 후보창 위치가 확인 범위에 포함되는지 다시 물었고, 해당 항목도 모두 정상이라는 확인을 받았습니다. 이 보고는 현재 NeoForge 실행의 실사용 확인이며, 다른 모든 로더·버전에서 같은 항목을 직접 관찰했다는 뜻은 아닙니다.

### 배포 판단과 검증 한계

로더별 26.3 기본 IME 실행, 공통 입력 경로의 자동 회귀 검사, 대표 저장·화면 검사와 위 테스터 확인을 합쳐 이번 베타의 필수 실사용 검사를 마감합니다. Fabric·Quilt가 공유하는 후보의 리소스 재로드는 Quilt에서 확인했습니다. 모든 세부 화면 검사를 모든 조합에서 반복한 것으로 확대하지 않습니다. 실행 클래스는 beta.6와 동일하며 이번 변경은 지원 선언과 검증 절차에 한정됩니다.

표지판의 Up/Down과 F3+T는 테스트 입력만으로 실제 키 전달을 확정하지 못했습니다. 방향키는 위 테스터 확인으로 보완했으며, 리소스 재로드는 언어 변경으로 별도 확인했습니다. F3+T 자체나 모든 GUI 배율·창 크기에서 후보창 위치를 검사했다고 주장하지 않습니다. 오프라인 계정의 인증·Realms 오류와 시스템 정보 수집 경고가 있으므로 경고 없는 실행으로도 표현하지 않습니다. 관찰한 범위에서는 Mixin 적용 실패나 게임 충돌이 없었습니다.

| `hangul-1.3.0-beta.7-neoforge.jar` | 55,716 bytes | `02e7648c39fd94bdf638231fa17086c978604c1226af1879b5fdc3c660d05c3a` |

위 해시의 세 파일은 GitHub 릴리스와 Modrinth에 배포했습니다. 실제 사용자 프로필과 월드는 변경하지 않았습니다.

## 1.3.0-beta.6 기록

2026-09-06 기준 배포 준비 검사를 마쳤습니다. 잔여 실사용 검사 전체에 대한 테스터의 완료 확인을 받았으며 원격 CI 26개 작업도 모두 성공했습니다. 자동 검사, 실행 중 관찰한 결과, 테스터 확인은 아래와 같이 구분합니다.

2026-09-06: 확장된 표지판·입력창 회귀 검사를 포함해 40개 로더·게임 조합과 최소 Fabric Loader 0.19.3의 3개 조합이 모두 통과했습니다. 최종 패키지·소스 압축파일 검사도 통과했습니다. 기존 후보와 비교하면 NeoForge 아이콘 메타데이터만 변경되었으며, 세 플랫폼의 입력 클래스는 변경되지 않았습니다.

## 최종 배포 검사

- 최종 파일의 해시와 기존 자동 검사 후보의 일치는 2026-09-06에 재확인했습니다. 이후 파일이 바뀌면 변경 범위에 맞춰 재검사합니다.
- [원격 CI](https://github.com/tdbgo/Hangul/actions/runs/34021385715)는 `1822826`에서 26개 작업이 모두 성공했습니다. Forge·NeoForge 전체 로더 검사와 최종 패키지 검사도 포함합니다.
- GitHub 계정과 공개된 커밋의 작성자·커미터를 대조했으며, 공개 이력·파일·메시지 검사를 마쳤습니다.
- 배포에는 실기 검증한 로컬 JAR을 유지합니다. CI 파일과 클래스 바이트는 모두 같으며, 해시 차이는 텍스트 줄바꿈과 Fabric 매니페스트의 파일 목록 순서에서 발생합니다.

실사용 검사 요청은 테스터 확인으로 마감했습니다. 이 문서는 검증 기록이며, 업로드 여부와 배포 파일은 Modrinth 버전 페이지에서 확인합니다. 26.3 시험 지원은 Fabric·Quilt에만 해당합니다.
