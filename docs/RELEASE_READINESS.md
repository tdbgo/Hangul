# 배포 준비 상태

## 1.3.0-beta.7 — 26.3 정식판 대응 후보

2026-09-17: 개발 중이며 아직 공개하지 않았습니다. Fabric·Quilt·NeoForge에 Minecraft 26.3 정식판을 추가합니다. Forge는 공식 26.3 로더가 없어 26.2까지의 기존 범위를 유지합니다. 모든 배포 JAR은 계속 26.2를 기준으로 빌드합니다.

- Fabric 0.19.5·Quilt 0.31.0-beta.4의 26.3 검사: 동일 Fabric 후보 JAR의 바이너리 검사와 13개 대상 클래스·42개 훅, 위젯·검색·표지판 검사 통과.
- NeoForge 26.3.0.3-beta의 26.3 검사: 동일 NeoForge 후보 JAR의 13개 대상 클래스·42개 훅, 위젯·검색·표지판 및 입력 백엔드 검사 통과.
- 최종 Windows 전체 검사: Fabric·Quilt 각 17개, NeoForge 5개, Forge 4개로 총 43개 로더·게임 조합 통과. 최소 Fabric Loader 0.19.3의 26.1·26.2·26.3-pre-2·26.3 추가 4개 조합도 통과했습니다.
- 각 실행에서 13개 클래스·42개 훅, 물리 키·단축키·일반 키 통과, 위젯·검색·표지판 검사를 수행했습니다. 한글 11,172음절 회귀 검사와 세 파일의 패키지 검사도 통과했습니다.
- 완료 기록 누락·이전 실행 기록 잔존·후보 해시 불일치가 실제 실패로 처리되는지 별도 검사했습니다. 정상 기록만 통과했습니다.
- 세 플랫폼 모두 배포 클래스 바이트가 beta.6와 동일합니다. 지원 선언과 검증·빌드 절차 변경이며 새 실행 의존성은 없습니다.
- 원격 CI와 26.3의 실제 Windows IME·한자 후보창·전체화면·배율 검사는 아직 수행하지 않았습니다. beta.6의 테스터 완료 보고를 이번 버전의 결과로 재사용하지 않습니다.

네이티브 검사가 끝나기 전에는 정식 배포로 승격하거나 Modrinth에 업로드하지 않습니다. 실제 사용자 프로필과 월드도 변경하지 않았습니다.

## 1.3.0-beta.6 기록

2026-09-06 기준 배포 준비 검사를 마쳤습니다. 잔여 실사용 검사 전체에 대한 테스터의 완료 확인을 받았으며 원격 CI 26개 작업도 모두 성공했습니다. 자동 검사, 실행 중 관찰한 결과, 테스터 확인은 아래와 같이 구분합니다.

2026-09-06: 확장된 표지판·입력창 회귀 검사를 포함해 40개 로더·게임 조합과 최소 Fabric Loader 0.19.3의 3개 조합이 모두 통과했습니다. 최종 패키지·소스 압축파일 검사도 통과했습니다. 기존 후보와 비교하면 NeoForge 아이콘 메타데이터만 변경되었으며, 세 플랫폼의 입력 클래스는 변경되지 않았습니다.

## 검증 범위

| 구분 | 확인 범위 | 한계 |
| --- | --- | --- |
| 자동 검사 | 동일 JAR의 메타데이터·바이트코드·Mixin 적용, 검색, 입력창 조합 이벤트와 원문 복원 | OS 키 전달·후보창·화면 픽셀을 검사하지 않음 |
| 표지판 회귀 검사 | 변환된 게임 클래스의 Up/Down/Enter 줄 이동·순환, 선택 교체, 한자 문자 확정, 취소·렌더 예외 복원 | 네이티브 창 없는 테스트용 상태에서 실행. 월드 저장·IME 후보 선택을 대신하지 않음 |
| Forge 26.2 실제 실행 | 한글 채팅·책·표지판 입력과 저장, 전체화면 전환, 리소스 재로딩, 블록 드롭, 저장·종료 | 다른 Forge 버전과 확장 IME 사례는 별도 확인 필요 |
| NeoForge 26.2 실제 실행 | 조합·Backspace, 채팅, 표지판 저장, 책 선택 교체·두 페이지 저장·재열기, 전체화면, 리소스 재로딩, 한자 변환 확인 | 아이콘 메타데이터 변경 전 파일에서 확인. OS 표지판 방향키 전달은 미확정 |
| Quilt 26.2 실제 실행 | 즉시 조합·받침 삭제, 채팅 단일 전송, 표지판 선택 교체·Enter 줄 전환·저장, 전체화면 왕복 | 책 추가 저장 검사와 OS 아래 방향키 전달은 관찰 기록만으로 확정하지 않음 |
| 26.3 시험판 | 선언된 버전의 자동 검사 | 아래 테스터 보고 외에 버전별 Windows IME·SDL3 실행 기록은 없음 |
| 잔여 실사용 검사 | 테스터가 전체 검증 완료를 보고함 | 버전·로더·파일 해시별 추가 실행 로그는 제공되지 않음. 위 실행 기록의 범위를 소급해 확대하지 않음 |

테스터의 완료 확인에는 직전에 남아 있던 책 추가 검사, 표지판 방향키 동작, 26.3 시험판 실사용 검사가 포함되는 것으로 접수했습니다. 이는 테스터 보고이며, 각 조합의 직접 관찰이나 해시가 확인된 실행 기록을 새로 확보했다는 뜻은 아닙니다. 26.3은 계속 시험 지원으로 표시합니다.

## 최종 배포 검사

- 최종 파일의 해시와 기존 자동 검사 후보의 일치는 2026-09-06에 재확인했습니다. 이후 파일이 바뀌면 변경 범위에 맞춰 재검사합니다.
- [원격 CI](https://github.com/tdbgo/Hangul/actions/runs/34021385715)는 `1822826`에서 26개 작업이 모두 성공했습니다. Forge·NeoForge 전체 로더 검사와 최종 패키지 검사도 포함합니다.
- GitHub 계정과 공개된 커밋의 작성자·커미터를 대조했으며, 공개 이력·파일·메시지 검사를 마쳤습니다.
- 배포에는 실기 검증한 로컬 JAR을 유지합니다. CI 파일과 클래스 바이트는 모두 같으며, 해시 차이는 텍스트 줄바꿈과 Fabric 매니페스트의 파일 목록 순서에서 발생합니다.

실사용 검사 요청은 테스터 확인으로 마감했습니다. 이 문서는 검증 기록이며, 업로드 여부와 배포 파일은 Modrinth 버전 페이지에서 확인합니다. 26.3 시험 지원은 Fabric·Quilt에만 해당합니다.
